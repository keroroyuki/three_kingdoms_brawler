# 三国战纪 · Web 版

> 横版清关动作游戏，无需构建、无需资源包，打开 `index.html` 即玩。

## 游戏概述

东汉末年，黄巾四起。玩家从涿郡起兵，一路经博望坡火攻、洛阳宫城决战，最终讨平黄天。本作采用程序化骨骼角色 + 国风手绘场景 + 纯合成音频，三关完整流程，支持五名可选武将、三段连招、冲刺/跳跃/完美格挡/必杀/超必杀。

## 操作方式

| 键位 | 功能 |
|------|------|
| `WASD` / 方向键 | 移动；上下调整纵深 |
| `J` | 普通攻击（三段连击；空中/冲刺中按 J 为跳斩/冲斩） |
| `K` | 跳跃 |
| `L` / `U` | 必杀技（怒气 ≥50 可发动）；怒气攒满 100 时同键发动的是**超必杀**（伤害 ×1.55） |
| `Shift` / 双击方向 | 冲刺 |
| `空格`（按住） | 防御；受击瞬间防御为完美格挡 |
| `Enter` | 确认 / 暂停菜单 |
| `Esc` / `P` | 暂停（切换窗口或标签页会自动暂停） |
| `M` | 静音开关（暂停菜单内也有对应选项） |

## 关卡流程

1. **第一章 · 涿郡起兵**（原野黄昏）
2. **第二章 · 博望坡火攻**（夜战火海）
3. **第三章 · 洛阳宫城**（雪夜宫殿）

每关包含 5 波敌人 + 1 名 BOSS，采用“波次闸门推进”：到达触发线 → 锁定竞技场 → 清剿敌人 → 解锁前进。

## 敌人与 BOSS

- 黄巾散兵 / 盾兵 / 枪兵 / 弓箭手 / 火术师 / 骑兵 / 精英 / 铁甲精锐
- 攻击令牌系统：同屏最多同时进攻的敌人受限，避免被围殴
- 三 BOSS：张角、张宝、天魔张角，拥有多阶段与远近技能组

## 记录与便利功能

- **最高战功**：通关或失败后自动记录到浏览器本地，标题画面展示；破纪录时结算页显示「★ 新纪录 ★」
- **自动暂停**：切换窗口 / 标签页时自动进入暂停并挂起音频，回来不会发现自己已经阵亡
- **自适应画面**：画面按窗口大小等比缩放，大屏或高分屏下后备缓冲同步提升，角色与文字保持锐利

## 技术说明

- 角色：程序化骨骼 + 胶囊体绘制，无外部贴图
- 场景：多层视差 + 天气粒子（桃花瓣、火星、飘雪）
- 音频：WebAudio 纯合成，含四首 BGM 与全套音效
- 交付：单 HTML + CSS + JS，无打包、无依赖
